It is not possible!! - Thinking outside the box

Created on 2020-02-26 18:35

Published on 2020-02-26 20:01

My son is in an after school program called Destination Imagination. DI as the program is known, is a collaborative creative problem solving competition. He is in a team with 6 other kids and they have to build a bridge with duct tape and playing cards that can transport weight. They get more points if the bridge is long, light and can transport a lot of weight. I have written about DI and how I feel this collaborative creative problem solving is a must have skill (not just for kids).

As one of the team managers (it is parent volunteer led) I hear a lot of 'It is not possible'. For example, one of the problem's they were trying to solve was around an object that was connect to a connection point with a connector. If the object is of length x and the connector is of length y, what could you change so that when connected the total length is not x+y, but longer. For example, in the image below if you wanted the total length to be greater than 10 units, how would you do it -

The initial reaction is 'It is not possible' and this is where it becomes fun as you start talking about 'real' constraints and 'artificial' constraints. For example, can I replace the object (lamp) with another that is of length 2 units (so total would be 11)? Turns out the object cannot be changed, that is a 'real' constraint. Can I replace the connection point, so it is not a point but is a box that the lamp is attached to. Thus adding to the length and turns out that too is a 'real' constraint. You cannot change the connection point.

So now we are into breaking the problem into smaller components and they start rephrasing the initial question. I have a connection point that I cannot modify and I have an object I cannot modify. So a length of 1 unit is fixed. If I want the total length to be greater than 10 units, logically it is the connector. Can I replace the connector with a longer one and the answer is no (that would be too easy)? So we start off with a connector that is of length 9 that when attached to an object of length 1 and hung from a connection point, ends up being longer than 10. Now we are back to 'It is not possible'. So going back to first principles, if an object of length 1 is attached to a connector of length 9 and hung, somehow it ends up with a total length >10. Parsing this statement, what you end up with is that somehow when hung the length expands -> stretches. At this point they start thinking about things that when hung stretch and end up with a bungee cord / elastic / rubber band etc. So replace the connector wire with a bungee cord and the length will be longer and then you get the - "but a lamp won't work with a bungee as the wire". At which point you have to realize that the lamp was just an example / illustration and it wasn't about hanging a lamp.

While this is a simple example, I see so many parallels with work. We are given a problem to solve, we are given some constraints, we make up some more constraints, we don't completely understand the problem to solve etc. We are then told think outside the box, without really being given a framework on how to think outside the box.

Thinking back to the lamp example here were some leanings for me on thinking outside the box -

  • Make sure you understand what problem you are trying to solve
  • Evaluate each constraint as 'real' or 'artificial'
  • Keep the real constraints, throw out the artificial ones
  • Keep rephrasing / restating the problem, so you don't lose sight as time goes along of what you started out trying to solve
  • Re-evaluate your real constraints to make sure they are still real.
  • Work as a team as there will be more ideas and the more diverse the team the more diverse the ideas
  • Sometimes taking a break helps
  • Any time you catch yourself saying - "It is not possible" pause and run through this list.
