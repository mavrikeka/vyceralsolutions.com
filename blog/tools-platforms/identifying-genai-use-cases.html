Identifying GenAI Use Cases

Created on 2024-08-08 09:27

Published on 2024-08-08 14:00

Having spent the last 6 months doing nothing but GenAI work and GenAI research and using GenAI products, I have been struck by one thing - there are some low hanging use cases that keep coming up again and again. E.g. Account research, people research, analyzing call transcripts (for various use cases - next steps, follow ups, handoff docs, building proposals etc.). It has made me wonder, if there is something inherently limiting about GenAI or is there an underlying framework that can explain this.

I've always enjoyed organizing chaos and building frameworks is fun for me and so I decided to break down these use cases to see if there is something core that will help me understand this. So here is my attempt at a framework that will let anyone look at a use case they have and figure out if GenAI is a good fit for it. One caveat, I stay away from coding / programming use cases with GenAI as that is not an area I am familiar with.

So the first key consideration is the underlying data that you want to use GenAI on. Is it -

  • Unstructured (documents, files, web sites)

  • Structured (data in systems)

Why this is important is because, GenAI is very very good at working with unstructured data. Since LLMs have been trained on all the information on the internet (web sites, articles, books, images, videos etc.) it is great at generating new information or synthesizing existing information. Another reason GenAI is great at this is because the probabilistic nature of GenAI (it is basically predicting the next word in a sequence with a high level of probability) is not a limitation. There are many ways to write a sentence and if I change a word here or there but keep the meaning the same, it is fine.

When it comes to structured data, GenAI is not that great. The main reason for this is because with structured data, we expect deterministic answers. If I give you a list of opportunities in a CRM (structured data) and I want to know what the total is, I want an exact answer. So GenAI by itself does not solve this need and it needs extensions to return the deterministic results.

Looking at this another way, with structured data we often deal with Analytical use cases and with unstructured data we often deal with Research and Content Generation use cases. There is another use case, that falls in the middle which is entering unstructured data into structured data sources (e.g. updating a notes filed in a CRM etc.). Below is a simple visual that represents this.

So, if you are looking at one of your use cases and you are wondering if GenAI is a good fit, ask yourself, what is the underlying data that is needed for this use case. If it is unstructured, go for it. If it is structured, take a pause.

Another lens to look at the data, is whether the data is Public (available on the internet) or Private (within your network / behind a paywall etc.). This becomes critical as it brings in some other considerations. Here is a visual that represents this.

EASY : If you have public data and it is unstructured, that is the sweet spot for GenAI use cases. If the data is already in the LLM, then all you need is ChatGPT (or Claude etc.). If you need more real time data that is not in the LLM, you will need to augment ChatGPT with Web Search. Some examples of use cases here are Account Research, Person Research etc.

EASY (but you need the right product) : The next set of use cases to tackle are with unstructured data that are private to you. For example, you have a bunch of proposals, projects you have done with your clients over the years and you'd like to use GenAI to search across these, build a searchable knowledge base etc. In this case you have to go beyond ChatGPT. You need products like www.anyquest.ai, that provide you with built in support for RAG (retrieval augmented generation - a very specific architecture to handle your documents) are secure (you do not want to put your data into ChatGPT). This opens up possibilities for things like analyzing call transcripts to generate hand off documents, generate proposals, next steps, pull out quotes etc. You can upload all the strategy documents your client shares with you and you can now summarize, understand, build POVs etc.

HARD : If your use case deals with structured data and is analytical in nature, it becomes much harder to leverage GenAI. You need to augment GenAI with the ability to integrate with the underlying systems (make API calls etc.), you also need to consider security and you possibly need to use tools to do some of the deterministic work and then use GenAI as a wrapper. If anyone is interested in reading more about this, here is a post I did around using GenAI for analytics. It is harder to find off the shelf products that can handle your use cases here. www.clay.com, is a great product if you are in the Sales/GTM space as it has a ton of integrations and also has web search, web scraping and GenAI built into it.

HARDEST : If your use case is a combination of public and private data and is a combination of structured and unstructured data, this will require a lot of thought and effort. Examples, like Klarna using GenAI to automate a lot of their support process are out there, but will take a lot of time, effort, setting up guardrails etc.

So next time someone comes to you with a use case and wants to know if GenAI is a good fit, as yourself what is the type of underlying data and where is it coming from. Nilesh Apte - per our conversation yesterday, hope this helps.
