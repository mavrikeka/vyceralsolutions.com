Client Context

Company Profile

  • Industry: Leadership Development & Executive Coaching
  • Firm Type: Mid-sized consulting firm
  • Client Base: Fortune 500 companies and scaling organizations
  • Service Model: Moving from consulting-only to consulting + software products

Application Overview

  • Platform: Custom web application built with Claude Code
  • Architecture: Full-stack app calling AnyQuest agents via API
  • Data: Client information stored in database
  • Deployment: Railway infrastructure
  • Purpose: AI-powered tools for client leadership assessments and development

The Challenge

Proof-of-Concept Blocked Enterprise Deployment

The firm had successfully vibe-coded a custom AI application that demonstrated compelling value to a large enterprise client. Business users loved the tool and agreed to beta testing. But the moment the contract was signed, the enterprise IT security team sent a comprehensive security questionnaire.

The Reality Check:

  • No testing framework (unit, integration, or E2E tests)
  • No security controls or infrastructure hardening
  • Basic username/password authentication (no enterprise SSO)
  • No documentation, runbooks, or incident response procedures
  • No compliance certifications (SOC 2, GDPR, ISO 27001)
  • Growing concern about AI security vulnerabilities in the news

The application worked beautifully for internal use, but enterprise procurement was dead in the water without compliance certification.

Our Solution

Comprehensive Compliance Transformation

We implemented a phased approach to transform the vibe-coded prototype into an enterprise-grade, compliance-certified platform while maintaining development velocity.

What We Built:

  • Testing framework: Comprehensive unit, integration, E2E, and automated UI/UX testing (Playwright)
  • Infrastructure hardening: Railway security controls, environment isolation, secrets management, Dependabot for dependencies
  • Enterprise authentication: Migrated from internal user/password system to WorkOS for SSO and identity management
  • Documentation systems: Process documentation, runbooks, incident response procedures, change management workflows
  • Evidence automation: SCRUT platform integration for policy documentation and automated audit trail collection
  • Development tooling: Linear + MCP integration for full-loop development (feature request → implementation → test case logging)
  • Audit coordination: Partnership with Constellation GRC through SOC 2, GDPR, ISO 27001 certification process

Implementation Approach

Four-phase engagement from gap analysis to certification

Phase 1: Gap Analysis

Weeks 1-2

  • Assessed application against SOC 2, GDPR, ISO 27001 requirements
  • Identified security vulnerabilities and infrastructure gaps
  • Mapped compliance controls to application architecture
  • Prioritized remediation based on audit readiness timeline
  • Established baseline for evidence collection

Phase 2: Parallel Build

Months 2-4

  • Testing: Implemented Playwright for E2E + UI/UX automation, Jest for unit tests
  • Security: Deployed WorkOS for enterprise SSO, Dependabot for dependency scanning
  • Infrastructure: Hardened Railway deployment, implemented secrets management, environment isolation
  • Documentation: Built runbooks, incident response procedures, change management workflows
  • Development loop: Integrated Linear + MCP for feature tracking and automated test case management

Phase 3: Audit Preparation

Month 5

  • Deployed SCRUT platform for policy documentation and evidence automation
  • Configured automated evidence collection for SOC 2 controls
  • Documented GDPR data handling and processing procedures
  • Prepared ISO 27001 information security management system (ISMS)
  • Conducted internal readiness assessment with Constellation GRC
  • Remediated gaps identified in pre-audit review

Phase 4: Certification

Month 6

  • Coordinated with Constellation GRC auditor for formal assessment
  • Provided evidence packages via SCRUT for all three frameworks
  • Responded to auditor findings and remediation requests
  • Achieved SOC 2 Type 1 certification (controls designed appropriately)
  • Achieved GDPR and ISO 27001 compliance certification
  • Established ongoing compliance monitoring and evidence collection
