The Context

The Challenge

Leadership development firm needed to build confident Claude fluency across 30 consultants—transforming their existing Claude Enterprise subscription from underutilized technology into daily operational capability for client research, content creation, and session preparation.

  • Low baseline usage: Claude Enterprise subscription in place but minimal daily adoption by consultants
  • Consulting-specific workflows: Generic AI training wouldn't address client intelligence, framework application, or session preparation needs
  • Time constraints: Consultants needed practical, immediately applicable skills—not theoretical AI education
  • ROI pressure: Enterprise subscription required measurable adoption to justify continued investment

The Core Problem: Consultants had access to powerful AI tools but lacked the structured training, consulting-specific examples, and ongoing reinforcement needed to integrate Claude into daily workflows.

The Solution

Focused 3-session capability building program with consulting-specific examples, live practice sessions, and 8 weeks of office hours reinforcement—designed to turn passive access into confident daily usage.

Program Outcomes:

  • 87% daily usage — Consultants actively using Claude 30 days post-training
  • 15+ consulting use cases — Client research, framework application, session prep, content creation, executive profiling
  • Custom prompt playbooks — Consulting-specific templates for recurring workflows
  • Live M365 integration — Deployed Microsoft 365 connector for seamless access to firm knowledge base
  • 65% office hours attendance — Consistent participation in weekly reinforcement sessions

Program Structure:

  • Session 1: AI Foundations + Claude Interface (GenAI basics, prompting framework, consulting examples)
  • Session 2: Advanced Features (Extended Thinking, Projects with client context, system instructions for consulting roles)
  • Session 3: M365 Integration + Skills (Live SharePoint/OneDrive demo, Skills for recurring workflows, use case mapping)
  • 8 weekly office hours: Live prompt refinement using real consultant examples, M365 troubleshooting
  • Deliverables: Consulting AI Handbook, prompt playbook templates, priority use case artifact

The Learning: Professional services firms need role-specific training with live examples from their actual work—generic AI training produces awareness, not adoption. Every session used real consulting scenarios and ended with working deliverables.

Measurable Business Impact

Adoption Metrics

  • 87% daily usage — Consultants actively using Claude in their workflows 30 days post-training
  • 100% session participation — All 30 consultants attended all 3 core sessions
  • 65% office hours attendance — Consistent engagement in weekly reinforcement sessions
  • Full M365 deployment — All consultants have live access to firm knowledge via SharePoint/OneDrive connectors

Use Case Discovery

  • 15+ consulting use cases identified: Client research, framework application, session preparation, content creation
  • Top applications: Pre-engagement client intelligence, leadership assessment analysis, session material preparation
  • Priority use case delivered: Working Claude Skill for client research workflow with documented process
  • Custom prompt templates: Reusable playbooks for recurring consulting workflows

Capability Building

  • Foundational fluency: All consultants can confidently prompt Claude for daily tasks
  • Advanced features mastered: Projects with client context, system instructions, Extended Thinking for complex analysis
  • Skills deployment: Consultants built and installed working Claude Skills during training
  • Knowledge integration: Team can access firm's SharePoint knowledge base directly through Claude

Strategic Foundation

  • Enterprise license ROI: High daily usage validates Claude Enterprise subscription investment
  • Consultant productivity: AI-assisted research and content creation frees capacity for client-facing work
  • Competitive positioning: AI-fluent consultants deliver faster, more thorough client intelligence
  • Scalable foundation: Proven program can extend to new consultant hires
